## Owner decisions (answered 2026-11-04, canvas version 71)

1. **Capture chord (G-13):** the boards say Ctrl+Alt+T (binding `Mod+Alt+T`); the code label follows in milestone 136 (E12-7).
2. **Add part (G-27):** removed from board 7c, stays excluded.
3. **Mermaid gate diagram (G-07):** dropped from the target. New requirement: ticket documents may contain Mermaid blocks; display (E12-6) and evaluation (engine parsers) must cope — roadmap E10-7.
4. **Design system wins (G-23, G-26):** pastels peach / pink / mint, radii 4/8/16, 13 px floor on mobile; Settings text size scale S / L / XL / XXL / XXXL with L = 17 px default; the code follows in milestone 136 (E12-7).

6. **Zod dropped (G-31):** ADR-0088 later changes and `specs/decisions.md`.
7. **Canvas (G-32):** 7e subtitle removed, 4d is a text-capture sheet; voice becomes a microphone button in the Assistant / chat composer (roadmap E12-8).

## What could not be verified

No app was run and no board was rendered: board comparison is by strings, structure and colours in the markup; `canvas.json` carries no per-board edit timestamps, so the owner's hand edits could only be dated for the 11 early boards that also exist as repo copies (ten differ). Pad and phone boards were compared by label, not by sample data. Row-level behaviour claims in docs/05 §5.41 were checked by symbol and path existence, not by logic. Everything marked "built" in the concept is "present in code and specs", not owner-verified.
