Crew Session Pool

Vorschlag für Frage 5: du sprichst mit Pia, jede Arbeit ist eine Session, eine Session fordert vor dem Start einen Slot und ein Modell vom Pool der Engine an. Beispielzahlen.

Der Weg einer Aufgabe

sequenceDiagram
  autonumber
  participant O as Owner
  participant P as Pia (Mission Control, direct call)
  participant E as Engine · Pool
  participant R as Crew runner
  participant S as Session (Ben)
  participant M as MCP (vault, tickets)
  O->>P: "Build T-0121" / Accept / a question
  P->>E: command (proposal confirmed by the owner)
  E->>E: rank: phase build, part size M, priority high → tier 2 of Ben's pool
  E->>E: request slot {persona ben, tier 2, context 40k}
  alt a slot is free
    E->>R: start session (model sonnet, run token)
    R->>S: spawn harness, instruction = prompt + skills + memory + plan
    S->>M: vault_search / tickets_read (token → ben → read only)
    S-->>R: turns, usage per turn
    R-->>E: telemetry: tokens, cost, gate verdict
  else no slot
    E-->>P: queued · waits for a sonnet slot (position 2)
    P-->>O: "T-0121 waits for a slot, Tessa's test finishes in ~5 min"
  end
  E-->>O: ledgers: ticket · persona · provider
