Working through a question

How often the assistant may look something up or make a change before it has to answer. When the rounds are used up it answers from what it has found so far.

On this computer

Which vaults the assistant can look into is chosen per question, with the vault button under the question field: it lists, searches and reads there (vault_list, vault_search, vault_read) and, if allowed here, edits, creates, moves and deletes notes (vault_edit, vault_write, vault_move, vault_delete). A deletion is always asked for.

Outside this computer

These tools send data to other services. A search query or a web address is the one way note content could leave the vault through a tool — with “ask”, you see every call before it runs. Whether a question may use them at all is chosen per question, with the globe button under the question field; it appears once something here is switched on.
